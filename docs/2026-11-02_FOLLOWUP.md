## Shared cavity

The saved example contains overlapping Minion Pro rows with 6 pt and 8 pt white strokes and black fills. The old neighbor filter required equal stroke reach. With only the upper stroke changed to 8 pt in a diagnostic copy, the cavity closed. This establishes an implementation boundary, not an InDesign limitation or a stale-screen explanation for this remaining gap.

The repair keeps each neighbor's width, join, and miter limit, unions their stroked regions, and fills only the enclosed cavities. It preserves the existing uniform-style path. Stroke color and tint must match; overprint and different frame linear transforms are excluded. Mixed-width hollow text remains excluded. Intervening artwork causes conservative refusal even when it lies inside the cavity without touching a glyph. Any shared fill whose contour or control points escape the search bounds is refused. Safety checks use the actual output's control-point bounds and resolved glyph bounds, so unrelated text in the broad neighbor-search margin does not block it. Earlier unsupported or incompatible text under that output blocks the fill conservatively; unavailable glyph bounds also refuse it. Existing caller-level letter protection remains unchanged; no extra graphics-port clip is added.

Work is bounded to 16 neighbor style groups plus the current frame and 200,000 contour segments. Mixed styles within one frame still use the existing per-run fallback. Very wide neighbors beyond the current frame's search margin and large-scene performance remain unverified.
