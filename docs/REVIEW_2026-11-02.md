# StrokeMaster closeout review, November 2, 2026

This review covers the Illustrator triangle and separate-story corrections, InDesign small-hole and screen-refresh fixes, associated switches, documentation, and regression fixtures. It excludes the separate film and Twitter work. Source publication and installation of a new production binary are separate steps.

## Corrections

InDesign's spread-invalidation callback did not run when intervening artwork was removed. The replacement document observer receives lazy model notifications after edits, including undo and redo. It invalidates cached text and its ancestor shapes, then requests view repaint without executing document commands. Frame identities are recorded even before their first overlap, deleted identities are pruned before lookup, and live spread history is retained until document close or correction is disabled. Refused snapshots are cached for the parcel and graphics port instead of retried for every glyph. Failed snapshots still record the current frame for later cache invalidation. New/open and revert lifecycle signals attach the observer; close and pre-revert signals detach it.

Native text ink is measured separately from the generous Close holes redraw bounds. When Close holes is off, the existing parcel ink calculation remains unchanged. Geometry bounds still participate in occlusion. Close holes with overflowing paragraph decorations, table content, or inline artwork needs additional coverage; glyph bounds alone do not establish every painted extent.

The shared geometry core collects small enclosed holes at both the actual stroke reach and the enlarged reach used for nearly touching strokes. The [small-hole report](INDESIGN_SMALL_HOLES_2026-11-02.md) records the failing regression, correction, and host PDF measurements. Illustrator's owner triangle retains all three corners with a limit above its actual tangent ratio, and the two-live-story fixture uses measured glyph bounds rather than point-text frame bounds.

The compiler test child now starts with a minimal Windows PATH before loading MSVC. This avoids an unquoted PATH assignment in Visual Studio's optional vcpkg initializer without changing machine configuration. The installer rejects ambiguous multiple-plugin backups unless a plugin name is supplied. The two Illustrator regression fixtures refuse to run without an isolated desktop and private settings.
