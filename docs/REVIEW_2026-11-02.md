# StrokeMaster closeout review, November 2, 2026

This review covers the Illustrator triangle and separate-story corrections, InDesign small-hole and screen-refresh fixes, associated switches, documentation, and regression fixtures. It excludes the separate film and Twitter work. Source publication and installation of a new production binary are separate steps.

## Corrections

InDesign's spread-invalidation callback did not run when intervening artwork was removed. The replacement document observer receives lazy model notifications after edits, including undo and redo. It invalidates cached text and its ancestor shapes, then requests view repaint without executing document commands. Frame identities are recorded even before their first overlap, deleted identities are pruned before lookup, and live spread history is retained until document close or correction is disabled. Refused snapshots are cached for the parcel and graphics port instead of retried for every glyph. Failed snapshots still record the current frame for later cache invalidation. New/open and revert lifecycle signals attach the observer; close and pre-revert signals detach it.

Native text ink is measured separately from the generous Close holes redraw bounds. When Close holes is off, the existing parcel ink calculation remains unchanged. Geometry bounds still participate in occlusion. Close holes with overflowing paragraph decorations, table content, or inline artwork needs additional coverage; glyph bounds alone do not establish every painted extent.

The shared geometry core collects small enclosed holes at both the actual stroke reach and the enlarged reach used for nearly touching strokes. The [small-hole report](INDESIGN_SMALL_HOLES_2026-11-02.md) records the failing regression, correction, and host PDF measurements. Illustrator's owner triangle retains all three corners with a limit above its actual tangent ratio, and the two-live-story fixture uses measured glyph bounds rather than point-text frame bounds.

The compiler test child now starts with a minimal Windows PATH before loading MSVC. This avoids an unquoted PATH assignment in Visual Studio's optional vcpkg initializer without changing machine configuration. The installer rejects ambiguous multiple-plugin backups unless a plugin name is supplied. The two Illustrator regression fixtures refuse to run without an isolated desktop and private settings.

## Independent adversarial review

Several read-only Claude API reviews covered bounded parts of the change. One completed response was lost to a local console-encoding error; later runs save directly as UTF-8. None is claimed as an exhaustive audit of every file or as host execution. Reports are retained locally under *build/closeout-2026-11-02/*. Findings were checked against source and host evidence rather than accepted as runtime results.

The first review identified missing first-overlap invalidation, history eviction, stale UID lookup, and obsolete user documentation. The follow-up identified text-change notifications as a remaining gap; a lower-frame edit reproduced stale red ink, and direct story subscriptions fixed it. Document protocols now use lazy-only subscriptions to avoid duplicate forwarding. Direct story subjects retain regular and lazy subscriptions because the tested text edits required regular-event bridging; duplicate story refreshes remain possible. Both reviews also raised bounds, lifecycle, and untested-display concerns. Documentation now distinguishes supported test results from those limits.

## Remaining owner and certification checks

- GPU preview and actual interactive painting need an owner witness. Hidden PrintWindow capture omitted the page with GPU enabled and was rejected as evidence.
- The inspected two-window cases pass after switching windows; repaint of a genuinely inactive window without activation remains unverified.
- Cross-parent-page text correction and very large snapshots remain outside this screen certification. Snapshot limits are 400 lines per visited column and 65,536 visited items; fallback rendering is not equivalent to the verified snapshot route.
- Close holes with decorations or inline content extending outside a frame, selection-export bounds, and canceled close/revert lifecycle paths need additional coverage. Glyphs with their own transformation matrices also need an occlusion-bounds test; ordinary frame-transform coverage does not certify those glyph matrices.
- Style-definition edits, nonprinting items in Preview, and the first edit after a canceled close remain unverified. A new screen snapshot reattaches the observer, but that alone does not prove the first edit was refreshed.
- Groups of stroked paths and compound paths are treated as outlined text for rounded tips; this also includes ordinary shapes with those structures. The tooltip now states this boundary. Large outlined groups still repeat sibling scans, so large-group performance is unverified.
- Check keyboard navigation of the introductory modeless notice in both hosts. Its seen-version value is stored per user and host, separately from correction settings.

The latest focused API review found no confirmed correctness defect in the idle task's lifetime, visibility map, cancellation, or coalescing. Its suggestion to return an end-of-time value was not adopted: the SDK's *CIdleTask.h* explicitly directs callers to uninstall the task and says the return value is then ignored. Review hypotheses about recomposition and lifecycle remain certification requests.

An installed engine must be reloaded by restarting InDesign. Illustrator likewise needs a restart after replacing its plugin. Existing PDFs retain the paths exported by the engine that produced them.
