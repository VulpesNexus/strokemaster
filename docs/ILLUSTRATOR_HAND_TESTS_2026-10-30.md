# Illustrator hand tests — October 30, 2026

Scripts cannot click, type, or press keys the way a hand does in Illustrator: a scripted menu call skips the checks a real click goes through, and posted input never reaches Illustrator's tools. These tests cover what only a hand can. Each takes a minute or two.

## Before you start

1. Quit Illustrator if it is running, then start it again, so it loads the current StrokeMaster build (region-prep-27 for the first round; region-prep-29 for the retests at the end).
2. Open *StrokeMaster/build/look/hand-tests-2026-10-30/StrokeMaster hand tests.ai*. It is synthetic: five numbered sections, each labeled with what it is for. Work on it freely; it is regenerated by *tools/jsx/ai-hand-tests.jsx*.
3. Open the panel: *Window > StrokeMaster*.

To report, reply with the test numbers and **pass** or **fail**, and for a failure what you saw (a screenshot helps). Annotating a PDF works too.
