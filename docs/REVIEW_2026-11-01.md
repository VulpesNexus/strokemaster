# Adversarial review, 2026-11-01

Five read-only Claude agents (Opus) reviewed the repository from the inside out, one area each: the shared geometry cores, the InDesign engine and panel, the Illustrator correction logic, the Illustrator automatic correction and panel, and the promises in the docs against the code and the tests. They cost $10.88 of API credit together. Their reports are worker output: each finding below says how far it was checked here.

- **Confirmed:** read here end to end (and against the SDK where it says so).
- **Agent-confirmed:** the agent traced it through the code; not re-read here.
- **Plausible:** needs a host test or fault injection to settle.
- **Refuted:** contradicted by a test or a hand test.

## Critical

1. **Illustrator: turning a switch off can crash, through a paint field used after it is freed.** `Unroute` (*plugin/illustrator-probe/RegionProbe.cpp* about line 1431) removes the route's stroke field with `RemovePaintField(p, field, true)`, then reads it with `GetStroke(field, …)` to give the lifted stroke back to each frame. The SDK says `true` disposes of the field (*AIArtStyleParser.h*, `RemovePaintField`). It is reached whenever a story group whose stroke was lifted from its frames is taken apart: *Strokes added through the Appearance panel*, *Strokes behind other letters' fills*, or *Across threaded text frames* turned off. The prep-36 host test passed only because the freed memory still held the stroke. **Confirmed.** Fix: read the stroke before removing the field.

## High

2. **InDesign: *Trim glyph tips* does nothing on live text unless *No miter spikes in live text* is on.** Tips are trimmed only inside the miter correction (`CorrectMiter`, *IseStrokeBehindAdornment.cpp*), which requires `text_miter` (*IseCrossFrame.cpp* `FromSettings`); the panel leaves the switch enabled and its tooltip promises live text. **Confirmed.** Fix: run the corner pass for tips when either switch is on, giving interior corners their whole miters back when `text_miter` is off; or gray the switch for live text and say so.
3. **Illustrator: frames the user took back are corrected again.** `Reapply` adds every frame of a story with a marked frame, and every frame of a routed story group, with no `Released` check; `AutoCorrect` widens new art to its whole story the same way; `Mark` then clears the released mark. A hand-set limit on one frame of a threaded story is overwritten by the next switch change or edit of another frame, contrary to *What to know* ("Your hand wins"). **Confirmed** for `Reapply`; agent-confirmed for `AutoCorrect`. Fix: skip released items in both widenings (and locked or hidden ones in `AutoCorrect`).
4. **Illustrator: `Reapply` overwrites hand changes the timer never saw.** A limit changed where StrokeMaster is not running (a colleague's copy, or while *Correct automatically* was off) is rewritten on opening with *Also documents as they open* or at the next switch change, since `Reapply` corrects with `refix=false` and `Overridden` is checked only on the re-fix. Agent-confirmed. Fix: have `Reapply` check `Overridden` against each item's record.
5. **Illustrator: undoing *Undo StrokeMaster Switches* leaves the document out of step.** The memo of applied switches is set when `Reapply` runs and not restored by undo, so after undo the art follows the old switches while the panel and the memo say the new ones, and nothing reapplies them. Agent-confirmed. Fix: compare against the switches recorded in the document (a dictionary entry written in the same undo step) rather than a memo.
6. **Illustrator: a group taken apart early in a timer tick is still fixed later in the same tick.** `Refix` collects the items due, then `AutoCorrect` may dissolve and dispose a story group among them, then `FixItems` runs on the stale list. Plausible (both events must land in one tick). Fix: drop items that are no longer valid art before `FixItems`.
7. **InDesign: the clip that keeps a later frame's stroke off earlier letters may fail in PDF and on overlapping contours.** *IseCrossFrame.cpp* builds it as a rectangle plus glyph outlines under an even-odd clip; the repository's own notes record InDesign's PDF port writing even-odd clips as nonzero, and glyphs with overlapping contours (variable fonts) stay inside an even-odd clip. Plausible. Check: threaded overlapping frames in a TrueType font, a CFF font, and Bahnschrift, exported to PDF.

## Medium

8. **Illustrator: the stroke order is not restored after *Strokes added through the Appearance panel* goes off and on with *Close holes* on.** The recorded order keeps the hole fill while the current order drops it, so `RestoreFieldOrder` finds different letters, does nothing, and deletes the record. **Confirmed.** Fix: strip the trailing hole fill from the recorded order too.
9. **Illustrator: "FillFirst off" is written without a record on three paths** (styled frames in `NativeRoute`, `Reroute`, a group whose fills and strokes disagree), so *Strokes behind other letters' fills* off never turns it back on. Agent-confirmed.
10. **Illustrator: story groups split by artwork are taken apart and rebuilt on every correction,** losing the group's own opacity, blend mode, name, or effects (a one-frame run in the same story marks the group as grown). Agent-confirmed.
11. **Illustrator, smaller automatic-correction gaps (agent-confirmed):** threaded frames on different layers are never released; past 4,096 corrected items the rest are never followed; pausing automatic correction drops a switch change still due to other open documents; a refresh-only flag set while typing swallows the next edits; documents are remembered by handle value; more than 500 items in one edit, or 20,000 in a document, are skipped without notice.
12. **InDesign: Center text miters are filled after the frame's whole text pass,** so a tip lands on top of later lines' letters where InDesign's order would cover it. Agent-confirmed; visible only with overlapping lines.
13. **InDesign: one missed end-of-drawing event leaves the cross-frame bookkeeping stuck** (`Begin` clears only at depth 0). Agent-confirmed; whether InDesign ever skips the event is unknown.
14. **InDesign: whole points on translucent objects are bounded by `GetPaintedBBox`,** which the repository measured to differ between screen and background export. Plausible.
15. **Shared cores (agent-confirmed):** the stroke-behind ledgers cannot tell a user's own None stroke or Bevel join from the plugin's mute; a closed one-segment contour, or a curve that loops back to its start, gets no corner stub; `TipReach` jumps when the shorter edge crosses the stroke's reach, so a slightly heavier stroke can get a shorter tip.
16. **Certification gaps (confirmed):** `compare` passes a measure that comes back empty (`None`, or `NaN`), never checks a value whose baseline is `null` (the *Correct Selection* job's gate), and compares extracted text by character count only, though its docstring promises an exact match.

## Low

- **Docs:** *docs/USING_STROKEMASTER.md* misses two switches in its table (*No miter spikes in shapes and outlines*, *Close holes inside the outline*), uses two old labels, and says no separate-stories switch exists while listing it. *LICENSE-EXCEPTION* says all source is GPL, but *plugin/third_party/clipper2/* is under the Boost Software License. The *One outline per word* tooltip names outside strokes only, though the switch also governs Center and Inside patterns on overlapping contours.
- **Settings files (both apps):** save failures are ignored by the panels; the InDesign `Save` creates a folder named after the file when *STROKEMASTER_SETTINGS* has no backslash; `enabled=false` reads as on; Illustrator rewrites the file in place.
- **Tests and tools:** *SettingsTests.cpp* overwrites and deletes the file *STROKEMASTER_SETTINGS* names when it is set; the certification ignores job exit codes, a timeout stops the whole run, two jobs skip the build check, and `--write-baseline` keeps failed jobs; `-Restore` in *tools/install-indesign-plugin.ps1* needs `-Name` for the panel.
- **Failure paths:** record writes and some `SetFrameChars` results are unchecked; a failed group rollback can still report `corrected`; a pattern stroker's refusal leaves the gap color under InDesign's own stroke for one draw; the *panel-align* bridge treats any input as Outside.

## Refuted

- **InDesign: "the note at the bottom of the panel never shows its tooltip."** The owner's hand test V3 (2026-10-31) saw the note's tooltip on hover.

## Suggested order

1. Finding 1 (crash), then 3, 4, and 8 (hand changes and records), then 2 (a switch that silently does nothing), each with a host test in *tools/jsx/*.
2. Finding 16, so the certification can catch the next regression, then 5 and 6.
3. The docs and license items, then the rest by severity.

## Resolution (2026-11-01)

Each finding, in the order above, with what was done and how it was checked. Illustrator: region-prep-41, certified against the prep-37 baseline, plus the host test *tools/jsx/ai-p41.jsx* run on prep-39 and on the fixed builds (*build/ai-review-41*). InDesign: engine `e1d8dda6` and panel `2897288b`, with the host test *tools/jsx/id-review.jsx* (*tools/run-id-review.ps1*) run on the old engine and the new one (*build/id-review*), and the 16 feature examples rerun against the previous engine.

1. **Fixed.** `Unroute` reads the lifted stroke before removing its field. The host test turns *Strokes added through the Appearance panel* off and on twice on the owner's *Tests.ai*: each frame gets its stroke back, as before, without reading freed memory.
2. **Fixed.** On live text the joins are drawn by the plugin for *Trim glyph tips* alone; with *No miter spikes in live text* off, the interior miters are filled back whole, as InDesign draws them. *Trim glyph tips* alone now changes 779 pt² (Outside) and 253 pt² (Center) where it changed nothing; with both switches at their defaults the output is unchanged.
3. **Fixed.** `Reapply` and `AutoCorrect` set an automatic flag, under which `FixItems` leaves released items alone; only *Correct Selection* pressed by the user takes them back.
4. **Fixed.** Before an automatic pass, `ReleaseOverridden` releases each marked item whose managed attributes differ from its record. Checked once, before the pass: a first version checked inside `FixItems`, and released the owner's text objects that the same pass had just reordered (caught by the host test). Host test: a star's limit set by hand while automatic correction was paused is kept, and the star released, at the next switch change (prep-39 adopted it).
5. **Documented.** Undo of *Undo StrokeMaster Switches* cannot be told apart reliably from other undo steps, and reapplying would fight the user's undo; *What to know* says to set the switch back too, or use *Correct Selection*.
6. **Fixed.** Items that are no longer valid art are dropped from the re-fix's list before `FixItems`.
7. **Fixed, and confirmed on overlapping contours.** The clip that keeps a later frame's stroke off earlier letters is built from each glyph's resolved region with `ise_miter::OutsideClip`, so it means the same under either fill rule. In Bahnschrift, the old even-odd clip let the next frame's stroke over the junction of the a's bowl and stem (186 pixels at 600 dpi); the new clip keeps the letter. The PDF fill-rule case did not reproduce in Times New Roman or Minion.
8. **Fixed.** The recorded order leaves out the Close holes fill, and an older record that kept it is read without it. It did not reproduce in the owner's file (the hole fill is gone whenever the strokes sit above the letters).
9. **Fixed.** FillFirst turned off is recorded on each frame (styled frames, a story whose fills and strokes disagree), and `Unroute` of a stroke route turns FillFirst back on.
10. **Fixed.** A story group counts as grown only when a frame of its story shares its parent with nothing visible between. Host test: on prep-39 the group lost its 50% opacity and its name at the next switch change; on prep-40 and -41 it keeps both.
11. **Mostly fixed.** Frames on other layers are released through `ReleaseOverridden` (the regroup path); the seen table holds 65,536 items, sorted, searched by binary search; pausing keeps a switch change still due to another document; closed documents are pruned before a memo is evicted; the refresh-only flag is cleared while typing. **Not fixed:** a document handle reused within one timer tick (not reproduced; a heuristic on the global time stamp was tried and dropped, since an undo could set it back). **Documented:** the 500- and 20,000-object limits.
12. **Documented** in *What to know*: drawing the Center miters in InDesign's order would need each run's stubs drawn before the later runs' fills.
13. **Fixed.** A bracket stack deeper than 8 starts over, and a full record table starts over rather than refusing every later record; unit test in *CrossFrameCoreTests.cpp*.
14. **Not reproduced.** A 50% triangle's whole point is identical in foreground and background PDF export (0 pt²); InDesign sizes its transparency group from the same painted bounds in each context.
15. **Fixed:** a closed one-curve contour has its corner, stub lengths follow the piece rather than its chord, and `TipReach` is continuous where the shorter edge crosses h and 2h (tips beside such edges are slightly shorter: 13–14 pt² in the Eagle Lake test, the k's stem foot); unit tests in *MiterCoreTests.cpp*. **Not fixed:** the ledgers' None or Bevel case, unverified (InDesign recomposes the run on such an edit, which renews its pointers).
16. **Fixed.** `compare` fails a value that comes back empty, NaN, or of another kind, and a null baseline needs a null result; `order` is compared; extracted text is compared exactly (`textExact`, in the prep-41 baseline); `--write-baseline` refuses a run with failed or missing jobs; `run` checks that the installed plugin is the build named, reports exit codes, and goes on after a timeout.

Low items: the usage guide's switch table, labels, and separate-stories line; the Clipper2 license note; the *One outline per word* tooltip (no longer "outside" only, at the same length so its wrap is kept); the InDesign settings parser (`true`/`false`, any other value keeps the default) and folder creation; atomic settings saves in Illustrator; the InDesign panel showing what the file holds when a save fails; the Illustrator bridge answering `unsaved`; *SettingsTests.cpp* ignoring *STROKEMASTER_SETTINGS*; `-Restore` finding the plugin a backup holds; the doubled stroke's record checked; type with mixed strokes doubled all or nothing; a failed rollback keeping its gate; *panel-align* taking only inside, center, or outside, and only while StrokeMaster is on. **Accepted:** a pattern stroker refusing after the gap color is painted (remembered per stroke class, so one draw; no class has refused in the certified suites).

## Second pass (2026-11-01)

The same five areas, reviewed again ($10.89 of API credit), with the first pass's findings and their resolution in hand: each agent checked the fixes in its area and looked for what the first pass missed. Most fixes were confirmed as correct (the crash, the stale group, the grown story group, the cross-frame clip, the settings handling, the bridge, the install script, the license and usage-guide edits). It found these, all resolved in Illustrator region-prep-42 and InDesign engine `1ca7e003` with panel `af522ba0` (since replaced, below):

**Illustrator**

- **Released art was still reordered, rerouted, and regrouped by the automatic passes** (fix 3 covered `FixItems` only), **and the frames a story pulls in were never checked for hand changes** (fix 4). `ReleaseOverridden` now runs on every item an automatic pass collects, the story's frames included, before anything is corrected, and returns only the items the pass may correct: not released, locked, or hidden. A threaded frame is judged against the character limits every frame of its story recorded, since reflowed text carries a sibling's limits (judged against its own, threading two corrected frames released them).
- **FillFirst left off** when a FillFirst route became a fill route or none: it is turned back on as the route is left. **`Unroute` turned FillFirst on for every stroke route**, overriding the user's own setting: only where `Reroute` turned it off, which is now marked.
- **A hand-set limit on a story group's route stroke was reset at the next tick:** the limits the fix leaves are recorded on the group; a group whose limits differ is released, and only *Correct Selection* takes it back. Checked by reading only: the bridge's `field-limit` acts on a group's frames, not the group, so the host test could not set it.
- **After a pause, other documents never took a later switch change** (a regression of fix 11): the documents that adopted the switches take them once, when correction resumes.
- **Smaller:** the refresh-only flag cleared when nothing changed; a switch change waiting on redo steps no longer rescans every tick, and art made since the last scan is corrected when it is applied; a closed document's memo no longer added back; the doubled dashed stroke keeps its dashes flag when aligning its dashes fails; the stroke-order record deleted only once restored, and an old record's hole fill dropped even when the hole is gone; `Unroute` refuses rather than lose a lifted stroke it cannot read; the settings parser takes `true`, `false`, `on`, and `off`, as InDesign's does; the panel's note says when the switches could not be saved.

**InDesign**

- **The frame last noted was cached across draws:** it is noted again with each outermost traversal.
- **One missed end-of-drawing event still left the bookkeeping stuck:** a spread draw that opens on the port of one still open starts it over (a partial draw inside one nests as before); a full record table refuses again, rather than dropping the traversal's own records. Unit tests in *CrossFrameCoreTests.cpp*.
- **Close holes filled the bodies of letters without a fill:** for such a run, the silhouette is filled outside the letters' region only. Host test: hollow "Bog" keeps hollow stems while its counters fill.
- **The tip trimming still jumped, in `TrimmedTip`:** a corner that is a tip beside an edge shorter than the reach now has its miter's reach grow from flush to whole as that edge grows to twice the reach (`NearTip`), in InDesign only, since Illustrator's limits draw `TrimmedTip`'s line; unit tests of the reach InDesign draws. About 17 pt² changes in the Eagle Lake test.
- **Smaller:** the cross-frame clip checked exactly (`ClipsOutside`), falling back to the even-odd clip; *Trim glyph tips* grayed when neither live text nor shapes are drawn by the plugin; the panel menu's *Restore Defaults* shows what the file holds when it cannot be written; a settings file that exists but cannot be read keeps the switches in force; the *No miter spikes in shapes and outlines* tooltip says the miters it gives back are Center strokes' (the only ones it affects); the `-RouteW` build compiles again.

**Certification tooling**

- Text compared exactly in every job (`textSame` beside each count, `textExact` in the story jobs); the runs job's gate read from its route record, where *Correct Selection* writes it (it compared null with null); a folder holding another build's results refused; the hidden-desktop launcher required; failed jobs make `run` exit nonzero, and a receipt that reports a failure makes the job fail in `measure`. The switch-off job now also turns *Whole points past the miter limit*, *No miter spikes in shapes and outlines*, *Trim glyph tips*, *Overlapping contours get one outline*, and *Also on dashed strokes* off and back on, reading each item's limit and effects back. The new values are in the prep-42 baseline.

**Docs:** the *What to know* description of *Trim glyph tips* states the rule as coded; the 500-object limit is for new art; the Illustrator README lists the fifth live effect.

## Third pass (2026-11-01)

Three agents, one each on Illustrator, on InDesign with the shared cores, and on the tooling with the docs ($5.03), checked the second round's changes and looked for medium findings or worse. Most changes were confirmed. It found these, resolved in Illustrator region-prep-43 and InDesign engine `f2c7a1dc`:

- **Illustrator, high, a regression of the second round:** `Reapply` took any art missing from the seen table for new, but the table holds only corrected art, so a switch change corrected every never-corrected object in the document. It now takes for new only unmarked art changed after the last scan (its time stamp).
- **Illustrator:** the timer's own re-fix judged a threaded frame against its own record, so text reflowing between frames released it; it now uses the story's recorded limits, as the automatic passes do. A released story group was still rerouted; it is now left alone before its route follows an edit.
- **InDesign:** striped strokes still jumped from a flush tip to a whole miter; their bands now take the same reach (`TipReach` for `NearTip` corners). Of the 16 feature examples, only the glyph-tips one changes (7 pt²).
- **InDesign, plausible:** a spread draw nested on the same port would start the bookkeeping over. Not reproduced: an InDesign page placed before threaded stories on the same page leaves their correction unchanged, on and off (0 pt²), so the reset is kept.
- **Tooling:** each stage of the switch-off job and the story jobs' recolored text are compared as text; and for each switch the job turns off, the certification records whether off changed the item and on restored it. That check found three of the five new flips testing nothing on their first items (a thick star, a path inside a compound letter, an even-odd compound path read without its pre-effects); new items, a notched hinge, the letter itself, and a nonzero dashed compound path, make all five act.

Low items noted by the third pass and left: a frame cache not reset when a missed end restarts the bookkeeping mid-draw; a thread's very first settings read meeting a locked file; the hollow Close holes clip used without the exact check; a certification folder made before *build.txt* existed; `--budget` returning 0 after a failed job.
