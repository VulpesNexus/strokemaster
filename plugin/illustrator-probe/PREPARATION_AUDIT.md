## Ownership and suite gates

The SDK Go message separates processing art from source art and forbids ancestor/document-tree mutation (*illustratorapi/illustrator/AILiveEffect.h:422–441*). Go rejects source aliasing, edits only its supplied processing leaf, preserves the root handle, and attempts to restore geometry and paint after mutation failure. It never disposes of callback input. Explicit creation owns only its new diagnostic line; attachment failure disposes of that line. Startup allocates state and registers handlers without artwork mutation.

`FromStrokeStyle` creates an entry reference; `AIDictionarySuite::Set` consumes it. `Get` creates a reference consumed by `ToStrokeStyle`. These ownership rules are documented in *illustratorapi/illustrator/AIEntry.h:232–251* and *AIEntry.h:517–530*. No second release is issued. The attachment parameter dictionary is released once after dependent operations. Per-call suite guards release acquisitions in reverse order. Entry allocation, dictionary Set failure, Entry-suite acquisition failure, and unsupported captured style each have cleanup mocks. The host test now demonstrates parameter use after initial dictionary release and same-process file reopen; it does not establish arbitrary style synchronization.

## Harness and verification checkpoint

Repository-relative *tools/jsx/ai-probe-native-stroke.jsx* retains the no-file smoke default. Its optional arguments are `outDir`, `runId`, `lifecycle`, `diagnostics`, `requireBuild`, and `expectedHostPid`. Lifecycle requires an existing output directory and new run identifier. Output collisions are rejected before journal creation and again before saves. The harness creates its own specimens, preserves prior documents, and restores the active document and interaction level. Failure diagnostics, including the raw returned payload, are journaled before parsing and before owned-specimen closure. A broken journal cannot prevent cleanup of an owned specimen.

Lifecycle mode is prepared to save a PDF-compatible AI, close the owned specimen, reopen the exact new file, compare two-anchor source geometry exactly, edit the reopened effect, require fresh successful dispatch, and save a separate PDF.
